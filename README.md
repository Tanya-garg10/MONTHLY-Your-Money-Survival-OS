# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/df0048d6-7c32-43e7-90b8-188232f21dbd

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `FEATHERLESS_API_KEY` in [.env.local](.env.local) to your Featherless API key
3. Run the app:
   `npm run dev`
